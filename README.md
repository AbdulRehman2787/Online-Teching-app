# Online Teaching & Learning Web Application
## مکمل آن لائن ٹیچنگ اینڈ لرننگ ویب ایپ

ایک مکمل، جدید، محفوظ اور خوبصورت Online Teaching & Learning Web Application جو ایک ٹیچر اور 15 سے 20 اسٹوڈنٹس کے لیے خاص طور پر تیار کی گئی ہے۔

---

### 1. بنیادی خصوصیات (Core Architecture)

- **صرف ایک Teacher Account**: ایپ میں صرف ایک ہی اکاؤنٹ ہے جو مالک، ایڈمن اور استاد کے تمام اختیارات رکھتا ہے۔ کوئی الگ ایڈمن اکاؤنٹ نہیں ہے۔
- **صرف ایک مستقل Classroom**: ہمیشہ ایک مستقل Class ID اور مستقل Link رہتا ہے۔
- **زیادہ سے زیادہ 20 اسٹوڈنٹس**: کلاس روم میں بیک وقت 20 سے زائد طلبہ داخل نہیں ہو سکتے۔
- **ایک وقت میں ایک Live Session**: صبح اور شام کے مختلف بیجز کے لیے وہی ایک لنک اور کلاس روم استعمال ہوتا ہے۔
- **طلبہ کا آسان داخلہ**: طلبہ کو رجسٹریشن یا ای میل کی ضرورت نہیں؛ صرف اپنا نام اور کلاس پاسورڈ لکھ کر داخل ہو سکتے ہیں۔
- **پاسورڈ تبدیلی اور فوری سیکورٹی**: ٹیچر جب کلاس پاسورڈ تبدیل کرے تو تمام پرانے طلبہ فوری طور پر منقطع (Disconnect) ہو جاتے ہیں۔
- **ویڈیو پرائیویسی (Video Privacy)**:
  - ٹیچر تمام طلبہ کی لائیو ویڈیو اور آڈیو دیکھ اور سن سکتا ہے۔
  - طلبہ صرف ٹیچر کی ویڈیو دیکھ سکتے ہیں؛ طلبہ ایک دوسرے کی ویڈیو **نہیں** دیکھ سکتے۔
- **لائیو پی ڈی ایف سنکرونائزیشن (Live PDF Sync)**:
  - ٹیچر جس پیج پر جائے گا، تمام طلبہ کا پیج خودکار طور پر بدل جائے گا۔
  - اسٹوڈنٹ کے پاس "Self-Study Mode" کا آپشن بھی ہے اگر وہ اپنی مرضی سے کتاب پڑھنا چاہے۔
- **لائیو وائٹ بورڈ انوٹیشنز (Live Annotations)**: ٹیچر کتاب پر جو بھی لکھے گا (Pen, Highlighter, Underline) وہ تمام طلبہ کو لائیو نظر آئے گا۔
- **مائیکروفون کنٹرول**: ٹیچر کسی بھی طالب علم کا مائیک بند یا کھول سکتا ہے۔
- **مکمل حاضری نظام (Attendance)**: طلبہ کے جوائن اور لیو ہونے کے درست اوقات ڈیٹا بیس میں محفوظ ہوتے ہیں۔

### 3. انسٹالیشن اور چلانے کا طریقہ (Windows Setup)

#### مرحلہ 1: پائتھن (Python) کی تنصیب
اگر آپ کے لیپ ٹاپ پر Python انسٹال نہیں ہے، تو [python.org](https://www.python.org/) سے ڈاؤنلوڈ کریں اور انسٹال کرتے وقت **"Add Python to PATH"** کے چیک باکس کو لازمی ٹک کریں۔

#### مرحلہ 2: 1-کلک سے چلائیں (One-Click Launch)
`D:\OnlineTeachingApp` فولڈر کھولیں اور **`run.bat`** پر ڈبل کلک کریں۔
یہ خودکار طور پر تمام پیکیجز انسٹال کرے گا اور سرور شروع کر کے براؤزر میں کھول دے گا۔

یا مینوئل کمانڈ پرامپٹ (CMD) سے:
```bash
cd D:\OnlineTeachingApp
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

براؤزر میں کھولیں: **`http://localhost:8000`**

### 4. ڈیٹا بیس (MySQL & SQLite)

ایپ میں سمارٹ ڈیٹا بیس فال بیک سسٹم موجود ہے:
- **MySQL (تجویز کردہ)**: اگر MySQL سرور آن ہو تو ایپ فوری طور پر MySQL کے ساتھ کنیکٹ ہو جاتی ہے۔ کنکشن اسٹرنگ `.env` میں تبدیل کی جا سکتی ہے:
  `DATABASE_URL="mysql+pymysql://root:password@localhost:3306/online_teaching_db"`
- **SQLite فال بیک**: اگر آپ نے ابھی MySQL انسٹال نہیں کیا تو پریشان نہ ہوں! ایپ بغیر کسی ایرر کے خودکار طور پر لوکل `online_teaching.db` پر کام شروع کر دیتی ہے تاکہ آپ فوری ٹیسٹ کر سکیں۔
- **Docker کے ذریعے MySQL اور LiveKit (اختیاری)**:
  اگر آپ ڈوکر استعمال کرتے ہیں تو صرف ایک کمانڈ چلائیں:
  ```bash
  docker compose up -d
  ```

### 5. مرحلہ وار استعمال (Step-by-Step Usage Guide)

#### 1. پہلی بار ٹیچر اکاؤنٹ بنانا (First-Run Setup)
جب آپ پہلی بار `http://localhost:8000` پر جائیں گے، تو ایپ خودکار طور پر `/setup` پر بھیجے گی۔
- اپنا نام، یوزرنیم، ای میل اور پاسورڈ درج کریں۔
- اکاؤنٹ بنتے ہی آپ لاگ ان ہو کر ڈیش بورڈ پر پہنچ جائیں گے۔
- اس کے بعد سیٹ اپ پیج مستقل طور پر بند ہو جائے گا۔

#### 2. ٹیچر ڈیش بورڈ (Teacher Dashboard)
- **Start Live Class**: کلاس شروع کرنے کے لیے بٹن دبائیں۔
- **Permanent Link**: اپنے طلبہ کو `http://localhost:8000/join` کا لنک فراہم کریں۔
- **Change Class Password**: جب بھی چاہیں کلاس پاسورڈ تبدیل کریں۔
- **Digital Library**: اپنی پی ڈی ایف کتب (PDF Books) اپلوڈ کریں۔
- **Attendance Logs**: طلبہ کے جوائننگ اور لیونگ ٹائم دیکھیں۔

#### 3. لائیو ٹیچنگ اسٹوڈیو (Live Teaching Studio)
- ڈیش بورڈ سے **"Enter Live Teaching Studio"** پر کلک کریں۔
- بائیں جانب کتاب سلیکٹ کریں؛ پین (Pen) یا ہائی لائٹر کے ساتھ پیج پر نوٹس لکھیں۔
- دائیں جانب آپ کو تمام طلبہ کے الگ ویڈیو باکسز نظر آئیں گے۔ آپ ان کے مائیکروفون کو کنٹرول کر سکتے ہیں یا کسی کو بھی کلاس سے باہر نکال سکتے ہیں۔

#### 4. اسٹوڈنٹ کا کلاس میں داخل ہونا (Student Experience)
- طالب علم `/join` کھولتا ہے۔
- اپنا نام اور کلاس پاسورڈ لکھتا ہے۔
- طالب علم کو فوری طور پر ٹیچر کی بڑی لائیو ویڈیو اور لائیو کتاب نظر آتی ہے۔
- طالب علم کسی دوسرے طالب علم کو نہیں دیکھ سکتا (مکمل پرائیویسی)۔
- ٹیچر جب پیج نمبر 15 پر جائے گا، طالب علم کا پیج بھی خودکار طور پر 15 پر پہنچ جائے گا۔
